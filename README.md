# SkillSphere

A student learning platform for discovering courses, developing skills, practising concepts, and tracking learning progress.

## Tech Stack
- React and Vite
- Python and Flask
- MySQL

## Features
- Student registration and login
- Student profiles and dashboard
- Course catalogue and enrolment
- Skill assessments and recommendations
- Learning roadmaps
- Practice zone
- Project submissions
- Achievements and certificates
- Admin dashboard

## Project Structure
- frontend/ - React application
- backend/ - Flask APIs
- database/ - MySQL schemas and SQL scripts
